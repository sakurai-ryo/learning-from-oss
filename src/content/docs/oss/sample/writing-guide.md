学び 1 つにつき 1 ページを作る。`group` にはそのページが属する群を書く。サイドバーは章の中でこの群ごとに畳まれ、群の並びは `sidebar.order` の若いページが属する順になる。

見出しは次の 4 つを基本にする。

## 何を学んだか

結論を先に 1〜3 文で書く。

## ソースコードのどこか

対象ファイルへのリンクと、要点となるコードを引用する。リンクはタグやコミットハッシュを含む URL にして、後から追えるようにする。

```ts title="src/index.ts"
export function example() {
  return "hello";
}
```

## なぜそうなっているか

その実装になっている理由。Issue や PR、コメント、テストコードから読み取れる意図を書く。

## どう活かすか

自分のコードにどう取り込めるか、逆に取り込むべきでない条件は何か。
