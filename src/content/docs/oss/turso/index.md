Turso Database は、SQLite を Rust で書き直した **in-process の SQL データベース** だ。旧称は Limbo。ライブラリとしてアプリケーションのプロセスに直接リンクされ、`.db` ファイルを読み書きする。

MySQL や PostgreSQL のようなサーバプロセスは存在しない。**接続は TCP のセッションではなく、ただの構造体**だ。それでいて、この章で扱う範囲だけでも MVCC、マテリアライズドビューの差分維持、マルチプロセス共有、Postgres ワイヤプロトコル、双方向レプリケーションが載っている。

**「サーバがない DB が、サーバ型 RDB の機能をどう後から取り戻すか」** — この章はそれを追う。

## この OSS について

- MIT ライセンス。ワークスペースは 40 以上のクレートからなり、Rust のソースは 753 ファイル・約 66 万行。エンジン本体の `core/` だけで 281 ファイル・約 37 万行ある。
- **SQLite との互換性が、設計上の憲法になっている。** ファイル形式はバイト単位で同じ。SQL の意味論も合わせる。さらに **`EXPLAIN` が吐くバイトコード列まで突き合わせる**。デバッグ手順に「sqlite3 と Turso で同じクエリを実行して差分を取る」スクリプト (`scripts/diff.sh`) が用意されている。
- **パーサは lemon が生成したものではなく、手書きの再帰下降**。SQLite のトークン型の一覧だけを引き継ぎ、文法の実装は 13,381 行 (うち 7,967 行がテスト) を手で書いている。`SELECT sum(x) OVER ...` の `OVER` がキーワードか別名かは前後を見ないと決まらない、という判定が 10 個あるからだ。
- **`async`/`await` を一切使っていない。** I/O 待ちが発生しうる関数は `IOResult<T>` を返し、待ちが必要なら呼び出し元に `IO` を返して帰る。呼び出し元は完了を待って **同じ関数をもう一度呼ぶ**。この「途中から再開する」が、B-tree の分割からチェックポイントまで、エンジン中のあらゆる関数に手書きの状態機械として現れる。
- **その結果、再入 (re-entrancy) が最大のバグ源になっている。** yield をまたいで状態を変えると、再開時にもう一度実行される。開発者向けガイドの `docs/agent-guides/async-io-model.md` は、その 1 点にほぼ全体を割いている。
- **アサーションが、そのままテストのプロパティ定義を兼ねている。** `turso_assert!` は通常ビルドでは `assert!` だが、`--features antithesis` を付けると Antithesis の自律テストに報告する形にコンパイルされる。「一度は成り立ってほしい」だけを表す観測用のアサーションまである。
- **テストの物量が本体に匹敵する。** 決定的シミュレータ、並行シミュレータ (Whopper)、Jepsen の Elle による異常判定、SQLancer/SQLRight、sqlite3 との差分オラクル、TLA+ 仕様。`testing/` の下だけで独立したツールが 10 個以上並んでいる。
- **開発ガイドが実装に追いついていない箇所がある。** `docs/agent-guides/` は「`.db-shm` は使わない・マルチプロセス非対応」「MVCC の GC は未実装」と書いているが、どちらも既に実装がある。この章はソースを正として書いている。

## 読む順番

クラサバ型の RDB は知っているが in-process DB の内部は初めて、という場合は [アーキテクチャのページ](./architecture/) から読んでほしい。接続・トランザクション・カーソル・ページキャッシュといった語彙を、MySQL との対応で全部ここで導入する。

次の [互換性の契約](./sqlite-compat/) は、この章の他のほぼ全ページの前提になる。「何が動かせなくて、何が自由なのか」がここで決まる。

「実行モデル」の 4 ページは前から順に読むのがよい。特に [`IOResult` のページ](./io-result/) は、ストレージ以降のほぼ全ページから参照される。

「SQL のパース」「クエリコンパイル」「同期」「品質保証」の各群は、それぞれ独立して読める。MySQL のオプティマイザと比べたい場合は [結合順序のページ](./join-order-dp/) から始めてもいい。パーサの 3 ページは前から順に読むと、「パーサジェネレータを捨てた理由」が 2 ページ目で回収される。
